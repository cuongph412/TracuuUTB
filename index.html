🔗 Google Sheets Backend
Dán URL sau khi deploy Apps Script. Để trống → dùng localStorage.
Hướng dẫn tích hợp Google Sheets:
1. Tải file Code.gs đi kèm
2. Mở script.google.com → Tạo project mới
3. Dán nội dung Code.gs vào editor
4. Sửa SPREADSHEET_ID và SECRET_KEY
5. Deploy → Web App → Anyone can access
6. Copy URL dán vào ô trên
